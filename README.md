# hxyfront-62012 染整异常放行台

源提示词编号：7

在染整小样管理台基础上补建的**异常放行台**。读数自动判定、异常处置、批次放行评审与履历留档。

## 业务规则

- **触发（任一即生成待处置记录，批次锁定不得评审）**
  - 温度连续 **3 分钟**偏离目标值 **≥ 2℃**
  - pH 超出 **[4.5, 7.5]** 区间
  - 泡沫量超过上限（默认 20mm）
- **解除（按异常发生顺序，不可跳过更早未闭环项）**
  - 温度项：只认**补时**解除
  - 酸碱项：须**两次复测合格**（不合格不累计）
  - 泡沫项：须先**排泡**，再**排泡后复测**合格
- **加急**：可将异常插到处置队列**队首**，但不解除顺序门槛——更早未闭环异常未闭环前，操作按钮锁定
- **改参数**：闭环后修改相关参数，自该类最早一条闭环异常起，本项及后续闭环结论全部**失效重开**；旧闭环履历只打失效标记、留档不删除；已放行批次同步撤回
- 无未闭环异常时批次方可评审放行

## 架构（三层分离）

```
src/
├── domain/            状态计算：纯函数 + reducer，零 React/DOM 依赖
│   ├── types.ts       数据模型
│   ├── rules.ts       判定规则、队列排序、可处置性
│   └── store.ts       业务 reducer（读数/补时/复测/排泡/加急/改参/评审）
├── persistence/       持久化
│   ├── storage.ts     localStorage 读写（带版本键与容错）
│   └── seed.ts        演示数据
└── ui/                页面交互（React）
    ├── useStore.ts        订阅桥：reducer ↔ 组件，自动落盘
    ├── BatchWorkspace.tsx 批次列表 / 读数上报 / 参数修改 / 评审
    ├── DispositionQueue.tsx 全局待处置队列（加急插队、顺序锁定）
    └── Timeline.tsx      履历时间线（失效留档标记）
```

列表、待处置队列与时间线均从同一份持久化状态派生，刷新后保持一致。

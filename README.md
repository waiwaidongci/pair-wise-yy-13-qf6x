# hxyfront-62012 染整小样异常放行台

源提示词编号：7

把染整小样台补成**异常放行台**：监控温度 / 酸碱值 / 泡沫三类工艺异常，自动生成待处置记录并锁定批次评审，异常按规则闭环后方可放行。

## 业务规则

- **触发待处置记录（批次锁定，不得评审）**
  - 温度相对目标偏离 **≥2℃ 且连续 3 分钟**（采样间隔 >90 秒不计连续）
  - 酸碱值超出 **4.5–7.5**
  - 泡沫超过批次泡沫上限
- **按发生顺序解除（FIFO）**：只允许处置发生最早的未闭环异常
  - 温度项：**补时**，累计达到保温要求即闭环（补时只解温度项）
  - 酸碱项：须**连续两次复测合格**，任一次不合格计数清零
  - 泡沫项：须先**排泡**再复测合格，复测不合格须重新排泡
- **加急**：加急项在处置队列中插队首并高亮，但闭环时**不能跳过**更早未闭环的异常（域层强拦截）
- **解除后改参数**：本项及其后所有已闭环结论**失效并打回重处**，旧事件履历与旧评审结论**留档**（时间线置灰标注作废），同时按新参数口径立即重判当前状态
- 同一批次同一类型在未闭环期间不重复生成记录

## 架构（三层分离）

| 层 | 位置 | 职责 |
| --- | --- | --- |
| 状态计算 | `src/domain/` | 纯类型 / 规则常量 / 选择器 / reducer，无 React、无 localStorage，时间与 id 注入，可单测 |
| 持久化 | `src/state/persistence.ts` | 仅负责 `AppState` 的 localStorage 读写与结构校验 |
| 页面交互 | `src/ui/` + `src/state/useStation.ts` | 把界面事件翻译成域动作；批次列表、处置队列、时间线均由同一状态的选择器派生，刷新后一致 |

- `domain/types.ts` 数据模型
- `domain/rules.ts` 阈值与判定原语
- `domain/selectors.ts` 批次状态、处置队列、复测进度、时间线等派生状态
- `domain/reducer.ts` 所有写路径（触发、补时、复测、排泡、加急、评审、改参数失效链）
- `domain/seed.ts` 用 reducer 派发动作生成 5 个演示批次（含三异常并存、完整闭环放行、改参数失效）
